# 🥔 감자마켓 (Gamja Market)

> **"포슬포슬 따뜻한 우리 동네 중고거래 이야기, 감자마켓"**  
> 빌드 도구 없이 브라우저에서 바로 열리는 초경량 정적 웹 애플리케이션 & Supabase 클라우드 실시간 데이터베이스 연동 프로젝트입니다.

---

## ✨ 주요 기능 및 화면 구성

감자마켓은 3개의 유기적인 화면과 강력한 클라우드 백엔드로 동작합니다:

### 1. 📋 [화면 1] 상품 목록 및 탐색
- **감자 테마 헤더**: 귀여운 감자 로고, 실시간 상품명 검색창, [글쓰기], [로그인] 버튼
- **7개 카테고리 필터**: `전체`, `디지털기기`, `가구/인테리어`, `의류`, `생활가전`, `도서/티켓`, `기타` 탭 실시간 분류
- **거래 가능만 보기 토글**: 판매 완료된 상품을 제외하고 거래 가능한 상품(`판매중`, `예약중`)만 선별 조회
- **반응형 카드 그리드**: 스마트폰(1열)부터 PC(3열)까지 최적화된 반응형 카드 레이아웃
- **상태별 배지**: 🟢 판매중 / 🟠 예약중 / ⚪ 거래완료 상태별 확연한 색상 구분

### 2. 🔍 [화면 2] 상품 상세 팝업 (모달)
- 상품 카드를 클릭하면 뜨는 부드러운 팝업창 (ESC 또는 바깥 배경 클릭 시 닫힘)
- 상단 50%를 꽉 채우는 대표 상품 이미지
- 판매 상태, 카테고리, 제목, 거래 동네, 업로드 시간, 가격, 줄바꿈이 지원되는 상품 상세 설명
- **판매자 프로필 카드**: 익명 닉네임, 프로필 이미지, 동네, **'매너온도 37.5℃ 🥔'** 게이지 바
- **관심(좋아요) 토글**: 하트(♥) 클릭 시 클라우드 DB의 `likes_count`가 실시간으로 증감

### 3. ✍️ [화면 3] 상품 등록 글쓰기 (모달)
- **간편한 상품 등록**: 이미지 URL(3가지 원클릭 추천 감자 프리셋 지원), 상품명, 카테고리, 가격, 상세설명, 거래동네, 판매상태 입력
- **0원 무료 나눔 감지**: 가격에 `0`을 입력하면 주황색 `🧡 따뜻한 무료 나눔 상품이에요!` 뱃지 실시간 표시
- **실시간 DB 저장**: 등록 즉시 Supabase `products` 테이블에 `INSERT`되어 새로고침해도 영구 보존

## 🔒 강력한 개인정보 보호(PII 배제) 및 보안 정책

감자마켓은 사용자 프라이버시 보호를 최우선으로 설계되었습니다:
- **개인식별정보(PII) 절대 미수집**: 실명(이름), 이메일 주소, 전화번호, 상세 집주소를 데이터베이스에 일체 저장하지 않습니다.
- **안전한 익명 식별자**: 난수 기반 `UUID`와 가상의 **익명 닉네임**(`포슬포슬이`, `감자조아` 등)만 사용합니다.
- **API 키 분리**: 브라우저 클라이언트에는 RLS(Row Level Security)가 적용된 공개용 `ANON_KEY`만 사용하며, 마스터 키(`SERVICE_ROLE_KEY`)는 로컬 환경에만 격리합니다.

## 🛠️ 기술 스택

- **프론트엔드**: HTML5, CSS3 (감자 브라운 테마 Custom Properties), Vanilla JavaScript (ES6+)
- **백엔드 / 데이터베이스**: [Supabase](https://supabase.com) (PostgreSQL, PostgREST API)
- **외부 라이브러리**: FontAwesome 6, Supabase JS v2 (CDN 방식)
- **빌드 도구**: 별도의 npm 빌드나 번들러 없이 웹 브라우저에서 `index.html`을 열면 즉시 실행됩니다.

---

## 🚀 빠른 시작 방법 (Local Run)

별도의 빌드 설치 과정 없이 브라우저에서 바로 열거나 간이 웹 서버를 띄워 실행할 수 있습니다:

### 방법 1. 파이썬 간이 서버 사용 (권장)
```bash
# 프로젝트 폴더에서 실행
python -m http.server 8080
```
웹 브라우저를 열고 `http://localhost:8080`에 접속합니다.

### 방법 2. 직접 열기
`index.html` 파일을 더블 클릭하여 크롬, 엣지, 사파리 등의 브라우저로 바로 엽니다.
